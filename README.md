## Hi, I'm SUWA Shigeki (@ztrehagem) 👋

Webフロントエンドを軸に、**型安全なアーキテクチャ設計**と**テスト・CI/CDの自動化による開発基盤（DX）構築**を得意とするエンジニアです。

---

### 💡 Core Strengths & Engineering Philosophy

- **型安全・状態管理を軸にした「間違えにくい」設計**
  - TypeScriptの厳格な型設計や適切な状態管理により、実装ミスを未然に防ぎ、保守性の高いフロントエンドアーキテクチャを構築します。
- **オートメーションによる品質担保と開発者体験（DX）の向上**
  - Playwrightを用いたVRT（Visual Regression Testing）、CI/CDパイプライン整備、デザインシステムのパッケージ化など、仕組みによって少人数でも高い品質を維持できる環境づくりに注力しています。
- **領域横断の「ハブ」としてのプロジェクト推進**
  - フロントエンド実装に加え、WBS作成・スケジュール管理、バックエンドとのAPI/IF設計、ヘッドレスCMSのデータモデリング、デザイナーとのUI/UX調整まで一貫して対応します。

---

### 🚀 Key Achievements（主な実務での取り組み）

- **デザインシステムのゼロからの立ち上げ・自動化基盤構築**
  - Reactコンポーネントパッケージをゼロから設計・開発。Storybook・GitHub Packages・AWS Amplify・Playwright VRTを組み合わせた自動テスト＆配信パイプラインを構築。
- **組織の技術スタック刷新・文化醸成**
  - JavaScript主流の環境でのTypeScript導入・社内啓蒙、Rails FE + Vue 構成から Rails + React SPA 構成や Next.js / Astro を用いた構成への社内主流転換、フロントエンドのテストコードを書く文化の定着を牽引。
- **技術支援・テックリード経験**
  - 受託開発での設計〜実装の一貫遂行および3〜4名規模のチームリードに加え、準委任契約にて他社プロダクトの技術支援・開発コミットに従事。
